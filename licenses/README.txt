# 江湖有田资源许可证登记

本目录集中登记工程引入的每一类资产：`ASSET_REGISTER.tsv` 为主表（一行一资产），
第三方清单 `third_party_assets.txt` 供快速审计，原始授权文本就近存放于对应资源目录。

当前已有：
- 第三方导入：Kenney UI Pack / RPG 扩展 / Tiny Town、Mushroom Village tileset（均 CC0）、
  LXGW WenKai GB（霞鹜文楷，SIL OFL 1.1，授权文本随字体存放于 assets/fonts/）。
- 待购买：Farm Top-Down Pixel Art Pack、Chinese Garden Tileset（仅预留目录，见备注）。
- 项目原创：`title_bg_png`（开始画面底图，tools/gen_title_bg.py 可复现生成）。

新增外部资源前，请记录：资源名称、作者、来源 URL、下载日期、版本、许可证、是否可商用、是否允许修改、是否需要署名、是否禁止再分发。
